## Deployment Options

### Option 1: GitHub Pages (Recommended - Free & Easy)

1. **Create a GitHub repository:**
   - Go to [github.com](https://github.com) and sign in
   - Click the "+" icon in the top right and select "New repository"
   - Name it something like `coinbase-bonus` or `crypto-referral`
   - Make it Public
   - Click "Create repository"

2. **Upload your file:**
   - On the repository page, click "uploading an existing file"
   - Drag and drop `coinbase-bonus.html` and `README.md`
   - Click "Commit changes"

3. **Enable GitHub Pages:**
   - In your repository, go to **Settings** > **Pages**
   - Under "Source", select "main" branch
   - Click "Save"
   - Your site will be live at: `https://yourusername.github.io/coinbase-bonus/coinbase-bonus.html`

4. **Optional - Make it the homepage:**
   - Rename `coinbase-bonus.html` to `index.html`
   - Your site will then be at: `https://yourusername.github.io/coinbase-bonus/`

5. **Optional - Custom domain:**
   - Buy a domain (e.g., from Namecheap, GoDaddy)
   - In GitHub Settings > Pages, add your custom domain
   - Update your domain's DNS settings to point to GitHub Pages

### Option 2: Netlify (Free - Drag & Drop)

1. **Sign up:**
   - Go to [netlify.com](https://netlify.com) and sign up (free account)

2. **Deploy:**
   - On your dashboard, drag and drop the `coinbase-bonus.html` file (or the entire folder)
   - Netlify will automatically deploy it

3. **Your site:**
   - Netlify gives you a random URL like: `random-name-12345.netlify.app`
   - Access your page at: `https://random-name-12345.netlify.app/coinbase-bonus.html`

4. **Rename and customize:**
   - In Site settings, change the site name to something like `coinbase-bonus-guide.netlify.app`
   - Rename the HTML file to `index.html` for a cleaner URL

5. **Optional - Custom domain:**
   - In Site settings > Domain management, add your custom domain
   - Follow Netlify's instructions to update DNS settings

### Option 3: Vercel (Free - GitHub Integration)

1. **Sign up:**
   - Go to [vercel.com](https://vercel.com) and sign up with GitHub

2. **Deploy:**
   - Click "New Project"
   - Import your GitHub repository
   - Vercel will auto-deploy

3. **Your site:**
   - Vercel provides a URL like: `coinbase-bonus.vercel.app`

4. **Updates:**
   - Any changes pushed to GitHub automatically deploy to Vercel

## SEO Tips

### After Deployment:

1. **Update the canonical URL:**
   - Open `coinbase-bonus.html`
   - Find the line: `<link rel="canonical" href="https://yourdomain.com/coinbase-bonus.html">`
   - Replace with your actual URL

2. **Submit to Google:**
   - Go to [Google Search Console](https://search.google.com/search-console)
   - Add your site
   - Request indexing for faster appearance in search results

3. **Create a sitemap (optional):**
   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
     <url>
       <loc>https://yoursite.com/coinbase-bonus.html</loc>
       <lastmod>2025-11-19</lastmod>
       <priority>1.0</priority>
     </url>
   </urlset>
   ```
   - Save as `sitemap.xml` and upload to your site root

4. **Build backlinks:**
   - Share on Reddit (r/cryptocurrency, r/CryptoCurrency, r/coinbase)
   - Post on Twitter/X with relevant hashtags
   - Share in crypto Discord servers and Telegram groups
   - Create a Medium article linking to your page
